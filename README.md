# NAOMI

Плагиновый хост-каркас на C# / WinForms (.NET Framework 4.8) с набором плагинов.

## Состав решения

| Проект | Назначение |
|--------|-----------|
| **SHELL** | Главная форма-хост: загружает плагины из `RELEASE\PLUGINS\*`, строит меню «Плагины» |
| **IDLL** | Контракт плагина (`I_Plugin`, `I_Plugin_Hostform`) |
| **TRANSLIT** | Транслитерация кириллицы по 15 стандартам (таблица `translit.csv`) |
| **UNLIMMATH** | Инженерный калькулятор с произвольной точностью (арифметика на строках) |
| **REF** | Справочник: математика, физика, химия, биология |
| **3D** | 3D-визуализация тетраэдра с логотипом Cyberdyne (OpenTK) |

## Сборка (Windows, Visual Studio 2022)

1. Восстановить пакеты NuGet:
   ```
   nuget restore NAOMI.sln
   ```
   или
   ```
   msbuild NAOMI.sln -t:Restore
   ```
   (подтягивает OpenTK 3.3.3 и OpenTK.GLControl 3.3.3 из `packages.config` проекта 3D)
2. Открыть `NAOMI.sln` и собрать (F6).
   Debug-сборки раскладываются: `SHELL.exe` → `RELEASE\`, плагины → `RELEASE\PLUGINS\<имя>\`.
3. Запуск: `RELEASE\SHELL.exe`. Кнопки плагинов появляются в меню «Плагины».

## Восстановление пакетов вручную

Если restore недоступен, скачайте пакеты с nuget.org и распакуйте в `packages\`:

- `OpenTK 3.3.3` → `packages\OpenTK.3.3.3\`
- `OpenTK.GLControl 3.3.3` → `packages\OpenTK.GLControl.3.3.3\`

## Тесты

Регрессионный набор для вычислительного ядра (`UNLIMMATH/CalcEngine.cs`) живёт отдельно
и запускается на .NET 8: 130+ проверок (арифметика, тригонометрия, комбинаторика,
теория чисел, парсер, обработка ошибок).

## Архитектура плагинов

Плагин — DLL в `PLUGINS\<имя>\` с классом `<имя>.Plugin : I_Plugin`.
Хост сканирует каталоги, создаёт экземпляры, регистрирует их и строит меню
из массива `P_Integr` (формат строки: `Имя|Действие|Подпись|Параметр|`).
Обмен данными идёт строкой `P_Proc`: `index|Имя|Действие|Подпись|Параметр|Текст`.
